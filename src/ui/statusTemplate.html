How this POC works

v1.0

Operation modes

Controlled by the VLT_ALLOW_REAL_UPLOADS environment variable.

Restricted (default)
Only the empty example.txt handshake file is permitted. Everything else is rejected at the controller.
Production
Full binary support — PDFs and standard assets up to 5 MB.

The canary file

Verifies the storage pipeline without spending quota:

Filename must be exactly example.txt, and file size must be 0 bytes.

Deletion

Removing a file runs a dual-wipe: the binary is deleted from Supabase storage and the metadata row is dropped from Postgres in the same request.

Future scope

This POC uses a static directory. Later iterations add dynamic folders, recursive moves, and custom metadata tags.
